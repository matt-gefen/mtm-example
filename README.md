# Overview

This is a demo landing page for MTM built with TanStack Start, using React and Vite.

The goal of this overview is to demonstrate a quality of life and design overhaul vision for the MTM site, using the landing page as an example implementation.

This is strictly a demo, the designs are not meant to be used in production nor are they representitive of any final product. The goal is to showcase a design idea and frontend refresh option done solo.

## Stack

- React
- TypeScript
- Vite
- TanStack Start (for ease of start and routing)
- TailwindCSS / Shadcn
- Netlify
- Prettier
- ESLint
